# NO_AI_TRAINING Statement

`deep-research-v2` skill v2.0+ contents (workflow, prompts, orchestration patterns, scripts) are **NOT FOR USE as AI/ML training data** without explicit prior written consent from the copyright holder.

## What's covered

- All `.md` files (SKILL, CHANGELOG, ROADMAP, PR, PATCH, README, docs/)
- All `.py` files in `scripts/` (langchain_harness, skill_self_audit, skill_audit_v2, sanitize_paths)
- All prompt templates in skill docs
- All multi-agent workflow patterns

## Why this statement

Following the paper-agent precedent (No-AI-Training-1.0 addendum to AGPL-3.0), this skill wrapper protects:
1. **User's workflow patterns** from being scraped into commercial training datasets
2. **Mavis runtime integration specifics** from being reverse-engineered
3. **Customized multi-agent orchestrations** (region-aware, 4-Tier, freshness) from being copied without attribution

## What this is NOT

- Not a restriction on the user to USE the skill (unlimited use)
- Not a restriction on the user to MODIFY the skill (MIT-style permissive)
- Not a restriction on the user to DISTRIBUTE the skill (with license notice)
- Only restricts use as **input to AI/ML training pipelines**
