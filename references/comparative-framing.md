# Cross-country comparative framing

Use this reference when a report draws lessons from one country or context for
another, especially when wording suggests the target should “avoid” the source
context's outcome.

This is a descriptive bias-control framework, not the transfer decision levels
in [transferability.md](transferability.md). Classify each compared issue by the target context's
observed state before recommending action. The four states are not a quality
ranking and different issues in one report may use different states.

## Four comparative states

- **⏳ Target not observed:** the source-context problem has not been established
  in the target context. Present it as a possible path warning, not something
  the target has already avoided or must inevitably experience.
- **🔄 Avoid mechanism replication:** a specific source-context mechanism,
  incentive, or implementation choice contributed to the problem. Name that
  mechanism; do not tell the target to avoid an entire country or outcome.
- **🔴 Present at a different degree:** a comparable issue exists in the target,
  but prevalence, severity, maturity, definition, or institutional setting
  differs. Quantify or describe the difference instead of saying it was avoided.
- **🔵 Positive lesson candidate:** a specific source-context mechanism or
  practice produced a relevant benefit. Treat it as a candidate lesson, then
  apply the transferability framework to decide direct use, adaptation, pilot,
  or rejection.

## Wording checks

Before writing “avoid,” ask:

1. Has the target problem actually occurred, or is it only a future warning?
2. Is the recommendation about avoiding a specific mechanism rather than
   assuming the target will repeat the source country's path?
3. If the issue exists at a different degree, does the wording preserve that
   difference instead of turning it into a binary success/failure claim?

Report the source observation, target observation, comparative state, and the
evidence supporting both sides. Absence of target evidence is not evidence that
the target avoided the problem; mark it unresolved when necessary.
